AI Photo-to-Film Kit — Prompt Browser

Copy-paste prompt templates for turning still photos into cinematic AI motion films. Search, filter by vertical and model, copy with one click. Every prompt states its model, version, duration, aspect ratio, and camera motion.

Prompts live in prompts/ in the repo; this page embeds the same data (regenerated with node scripts/build-web.js). Open this file directly in a browser — no build step, no server needed. See prompts/general/README.md for the prompt formulas used.
